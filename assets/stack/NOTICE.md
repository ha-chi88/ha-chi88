# Technology icons

TypeScript, React, Next.js, Expo, Node.js, Cloudflare, Hono, and Claude
icon paths are from
[Simple Icons](https://github.com/simple-icons/simple-icons), distributed under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Retrieved on 2026-10-26. Badge layout and colors are local presentation choices.

The React Native badge uses the React icon.
The Claude Code badge uses the Claude icon. The Codex badge uses a generic terminal
prompt symbol, not an official OpenAI logo.
The libSQL icon path is from the
[libSQL website favicon](https://github.com/libsql/libsql.github.io/blob/main/images/favicon/favicon.svg),
matching the owner's supplied hexagonal reference. Retrieved on 2026-10-26.
Its color is adapted to the local badge palette; its geometry is unchanged.
Brand names identify technologies used; they do not imply affiliation or endorsement.

## PostgreSQL

The PostgreSQL badge uses the filled elephant from
[Devicon's PostgreSQL SVG](https://github.com/devicons/devicon/blob/master/icons/postgresql/postgresql-original.svg).
Retrieved on 2026-10-26. The original path geometry is preserved. Colors are adapted
to the badge palette, the icon is displayed slightly larger, and the interior
details have an additional 1.2-unit stroke in the original 128-unit coordinate space
to improve small-size legibility.
